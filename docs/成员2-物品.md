# 成员二：物品模块

你只改 `items/`。运行 seed_demo 后，用 student1 登录。可以立即开发，不需要等待注册模块或预订模块。

## 要完成的功能

1. 浏览与搜索：现有列表加标题关键词、分类、校区筛选与分页，每页 20 条；翻页保留筛选参数。公开列表只含 AVAILABLE/RESERVED，详情可见 AVAILABLE/RESERVED/COMPLETED。
2. 发布：标题 1—60 字、描述 1—1000 字、价格 0—99999.99 元且最多两位小数、分类、校区、公开交接地点；seller 自动取当前用户，初始 AVAILABLE。
3. 我的发布：只显示本人物品，能进入编辑、上下架；显示状态与价格。
4. 编辑与上下架：只有本人 AVAILABLE 物品可编辑/下架；OFF_SHELF 可重新上架。编辑过期占用物品时，在确认所有权后用共同锁工具释放，再按新状态判断。RESERVED/COMPLETED/HIDDEN 不允许编辑。
5. 完善详情页，但保留公共预订按钮片段；卖家中心保留卖家确认片段。

## 开发边界

数据只用 `core.models.Listing`。可以加 items/forms.py、services.py、自己的模板标签与静态资源；禁止新建物品模型或改公共迁移。ModelForm 必须显式列可编辑字段，不能用 `fields='__all__'`。

编辑、上下架在事务内先锁 Listing，使用 `core.locking`。禁止接收客户端 seller/status；金额用 Decimal。只有自己才能查看隐藏/下架物品的管理信息，公开详情对这两种状态返回 404。

路由名保留 items:list/create/mine/detail/edit/take_off/relist。模板上下文物品始终叫 listing。保留：

```django
{% include "bookings/_reserve_button.html" %}
{% include "bookings/_seller_actions.html" %}
```

两个片段分别放详情和我的发布的每件物品中。当前禁用按钮等成员三自行替换，你不用实现预订函数，不需要导入 bookings.services。

在 items/开发记录.md 写实际测试和操作说明。只提交 items/，发 PR 到 main。
