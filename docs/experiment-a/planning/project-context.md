# 实验 X 实现约定

1. 使用现有 Python 3.13、Django 5.2、模板渲染与 SQLite 开发环境。
2. 只修改自己负责的 items 模块。工作流文件和产物归入 `_bmad-output`。
3. 公共模型、迁移、设置、公共模板和其他业务模块保持原状。
4. 所有身份均由 Django Session 得出，数据库查询始终先限制到本人记录。
5. 通过模型枚举校验状态输入，不维护第二份状态枚举。
6. 保持 `items:mine` 路由和卖家确认模板片段兼容。
7. 查询先过滤、排序，再在数据库层分页。时间相同的记录使用主键作排序依据。
8. 这条故事只有读取操作，保持数据库内容不变。
9. 项目测试走 Django 客户端。运行配置检查、迁移检查和与当前故事有关的测试。
10. 保留真实评审证据，尚未运行的检查标记为未执行。
