# 实验 X 需求

| ID | 可观察的行为 |
|---|---|
| FR-X01 | 登录卖家打开 `/items/mine/`，只看到本人发布的物品，默认查看全部状态，按最新发布排序。 |
| FR-X02 | 用户能用下拉框选择任意 Listing 状态。选中后只列出符合状态且归属本人的物品。未知状态等价于全部。 |
| FR-X03 | 每页最多 20 条，翻页保留所选状态。无效页码安全回退，空列表有明确提示。 |
| NFR-X01 | 保留现有详情、公开列表、卖家确认组件及登录要求。表结构、公共路由和状态枚举保持不变。 |

验收数据由评审阶段另行生成。首轮以实际 HTTP 响应和数据库断言为准。范围为现有卖家页，预订模块和公开首页不在本故事范围内。
