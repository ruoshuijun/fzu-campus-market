# 成员一：账号模块

你只改 `accounts/`。先运行 README 的启动命令，再读公共约定。基础登录/退出已经可用，**不要重新创建 Django 项目或用户模型**。

## 要完成的功能

1. 注册：username、密码、确认密码、昵称；重复账号、弱密码、密码不一致时明确提示。使用 Django UserCreationForm 或内置密码校验，不手写密码存储。
2. 登录：完善现有页面；正确密码登录，错误密码提示；支持合法的 next 跳转，不能跳转到外站。Django LoginView 已有基础支持。
3. 个人资料：登录后查看并修改昵称，使用 User.first_name，最大 30 字；不能在此改 username、管理员身份或密码字段。
4. 退出：保持 POST + CSRF，退出后个人页面要求重新登录。

## 文件和接口

`accounts/views.py`、`forms.py`、`urls.py`、`templates/accounts/`、`tests.py` 可修改。保留 `accounts:login/logout/register/profile` 路由名；已有公共导航会自动连接。

不改 core、config、公共模板，不新建 Profile 表；若认为必须加字段，先向成员四提出。注册时不能接收 is_staff/is_superuser；昵称在模板保持自动转义。

## 怎么算做完

至少检查：正常注册、重复账号、弱密码、密码不一致、登录失败、退出后访问、未登录修改资料、修改昵称、尝试注入管理员字段不提权。新注册学生能直接进入成员二/三页面，登录态不另起一套。

在 accounts/开发记录.md 写清运行方式、测试结果和未完成项。只提交本目录，发 PR 到 main；不要提交数据库和 .venv。
